# 生图提示词模板

每张图单独生成。身份图与母版承担不同角色：

```text
任务：生成一张 Silas 2.5D 真实物件场景图。

身份：使用内置 Silas 图作为 identity reference；只继承短黑发、narrow oval black sunglasses、暖灰褐立领套装、黑鞋和修长体态，不继承参考图布局。

母版：使用 {母版文件} 作为 composition reference；只抽取 {比例、留白、动作清晰度、信息密度}。当前图必须改变 {至少 3 个变异点}。

画面：{比例与背景}。真实主物件是 {物件}。Silas 正在 {核心动作}，身体重心与受力方向一致。画面 3 秒读懂为“{一句话}”。

材质：角色是 matte paper-clay 与 soft felt 的轻哑光 2.5D 质感；真实物件保留可信材质；统一柔和光影与接触阴影。

文字：只出现 {标签列表}，中文必须准确清楚；不增加标题、编号、说明段落或其他文字。

负面：不做真人、不做高亮玩具、不做 UI、不做 PPT、不做品牌标志、不做复杂背景、不堆叠物件、不复制母版空间拓扑。
```

长卷模式把“画面”改为超横版近白长卷、一条自然起伏路线、5-8 个不等距实物节点、左起右收；每个节点都要有 Silas 的具体动作。
