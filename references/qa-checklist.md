# 生成后 QA

## 必须通过

- [ ] 画面尺寸和模式匹配：标准 16:9，长卷约 2.6:1 到 3:1。
- [ ] Silas 的短黑发、窄椭圆黑墨镜、暖灰褐立领套装、黑鞋一致。
- [ ] 角色是轻哑光 2.5D，不是真人、塑料玩具或大头卡通。
- [ ] 小人承担唯一核心动作，重心、接触点和物件受力清楚。
- [ ] 真实物件、角色、标签的透视与光影处于同一空间。
- [ ] 画面有大留白，主物件不过大，配件不超过 2 个。
- [ ] 中文标签只有 2-4 个且完全正确，没有多余文字。
- [ ] 不看说明也能在 3 秒内说出冲突。
- [ ] 至少 3 个构图要素不同于所选母版。

## 长卷追加检查

- [ ] 5-8 个节点从左到右形成连续叙事。
- [ ] 路线自然起伏，节点不等距，不是平直流程图或规律波形。
- [ ] 每个节点都有实物锚点和 Silas 动作；没有虚构具体事实。

第一张结果一律标为候选。查看原图后逐项检查；任一必须项失败，就重写提示词或重新生成，不作为交付图。
