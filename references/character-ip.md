# Silas 2.5D 角色 IP

## 身份锚点

使用 `assets/identity/silas-2p5d-identity.png` 作为 identity reference，只继承角色身份，不继承参考图的排版或多视图构图。

固定识别点：

- 年轻东亚男性的极简 2.5D 化身，短黑发，轮廓干净。
- narrow oval black sunglasses，始终保留，镜片不透明，不改成普通眼镜或护目镜。
- 暖灰褐色立领套装，竖向细纹可轻微可见；黑色简洁鞋。
- 身体修长但不过度写实，头身约 1:5.5 到 1:6.5，动作轻巧。
- 面部信息克制，身份主要由发型、墨镜、立领套装和体态共同建立。

## 动作规则

- Silas 必须拉、推、接、挡、解、标、扶或筛，不能只站在旁边。
- 动作方向、身体重心和物件受力必须一致。
- 标准模式中角色高度通常占画面短边的 12% to 16%；只有动作可读性需要时才略微放大。
- 保留轻盈感，避免肌肉化、英雄姿势、真人摄影皮肤、Q 版大头和塑料玩具质感。

## 禁止项

- 不生成真实人像合成。
- 不把身份图里的四宫格、灰色影棚或站姿复制到成图。
- 不更换为帽子、彩色眼镜、运动服、长袍或明显品牌服装。
