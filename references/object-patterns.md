# 真实物件动作模式

## 六种标准关系

1. 拉入：纸签、夹子、绳带或文件入口向 Silas 施加拉力。
2. 涌出：票据机、抽屉、信封或托盘持续吐出任务，Silas 挡、接或推回。
3. 卡点：卷尺、挂绳、线轴或回弹带形成回流和结，Silas 集中处理卡点。
4. 审查：透明文件袋、夹板、红笔、卡尺或打孔器形成检查区，Silas 圈、量、改。
5. 重贴：标签机、布章、行李牌或抽屉标签改变身份定义，Silas 拉住或重新贴。
6. 筛选：茶漏、漏斗、滤纸或入口缝过滤卡片，Silas 推入、接住或救回。

## 原创约束

- 物件必须日常、可识别、能产生真实受力。
- 同一画面只保留一个核心物理冲突。
- 如果沿用母版的主物件，必须改变空间关系和 Silas 动作。
- 如果沿用母版的动作类型，必须改变主物件、配件和标签位置。
- 禁止把所有主题名词都画出来；禁止截图、界面、品牌标志和装饰性科技符号。

## 长卷物件

每个节点选择一个阶段记忆物：空白笔记本、钥匙、纸模型、反馈印记、线轴、打开的盒子等。物件不是图标，Silas 必须逐段与之发生动作。
